# AURA 0.20.4

- 플레이어 출력 기기명 오른쪽에 코덱명만 한 줄로 표시합니다. 예: 출력 · WF-1000XM5 · LDAC.
- 이미 블루투스가 연결된 상태에서도 현재 코덱을 조회합니다.
- 코덱 조회에 기기 등록을 요구하는 Android를 위해 설정 → 출력 기기에 공식 Companion Device 등록 기능을 추가했습니다. 사용자 승인이 필요합니다.
- 새 Android의 코덱명 메서드 차이를 처리합니다. 시스템이 반환한 현재 코덱 설정에서만 이름을 읽으며 추정하지 않습니다.

SM-S931N/API37 실기기에서 CDM 미등록 오류와 코덱명 메서드 오류를 재현하고 수정했습니다. 사용자 등록 승인 후 WF-1000XM5로 실제 재생하면서 플레이어의 LDAC 표시와 시스템 코덱 LDAC가 일치함을 확인했습니다. Release 빌드와 lintDebug/lintVitalRelease 통과.

# AURA 0.9.0 · 드래그·폴더 탐색·실시간 가사

## 스크롤과 상단바

목록의 플링 속도를 줄이고 최대 속도를 제한했다. 터치 시작 임계값도 늘려 작은 접촉으로 목록이 쉽게 움직이지 않도록 했다. 화면 전체 스크롤에도 같은 관성 조절을 적용하며 직접 드래그 거리는 유지한다. 플레이어 닫기 역시 더 분명한 하향 동작에서만 동작하도록 조정했다.

라이브러리 상단바의 거리 임계값을 넘으면 한 번에 교체하던 처리를 제거했다. 이제 16dp의 작은 움직임 여유 뒤 손가락 이동량에 비례해 실제 높이·내용 위치·투명도를 연속적으로 바꾼다. 느리게 움직이면 중간 높이를 유지하며, 손을 놓았을 때 중간 위치를 강제로 완전 열림/닫힘으로 바꾸지 않는다. 양 끝 근처의 정리와 펼치기 버튼에는 감속 애니메이션을 적용한다. 손을 뗀 뒤 목록의 관성만으로 상단바가 다시 열리고 닫히지 않는다. 완전히 접혀도 48dp의 제목·검색·펼치기 바는 남는다.

## 폴더 경로 탐색

폴더를 한 목록에 펼쳐 놓는 대신 저장소 → 등록한 음악 폴더 → 하위 폴더로 들어간다. 경로 표시의 각 단계와 상위 폴더 버튼, Android 뒤로 가기로 부모 폴더에 돌아갈 수 있다. 현재 폴더에 직접 들어 있는 곡과 하위 폴더를 구분한다. 폴더를 눌렀다는 이유로 모든 하위 곡의 재생을 시작하지 않는다.

로컬 SAF 문서 ID와 Drive 폴더 ID의 경로 목록을 검색 결과에 저장한다. 같은 이름의 폴더라도 등록 루트·저장소·실제 ID가 다르면 분리하며, Drive 폴더 이름에 `/`가 들어 있어도 새 검색 정보에서는 이름을 쪼개지 않는다. 기존 인덱스도 읽을 수 있으나 정확한 폴더 ID 경로를 저장하려면 라이브러리를 한 번 다시 검색한다. 경로 정보가 없는 이전 목록에는 안내를 표시한다. 탐색 범위는 앱에 등록해 검색한 음악 폴더다.

## 플레이어와 가사

곡 제목·아티스트·출력 칩·이동 버튼의 배치를 정리하고 가사/대기열을 작은 보조 동작으로 묶었다. 하단 가사는 현재 줄만 최대 두 줄로 보여 주며 다음 줄을 함께 붙이지 않는다. 일반 가사와 긴 오류 안내는 미리보기에 통째로 노출하지 않고 전체화면에서 확인하도록 안내한다. 앨범 표지의 정사각형 비율과 CENTER_CROP은 유지한다.

LRCLIB 정확 조회가 일반 가사만 반환해도 같은 제목·가수·재생 시간 조건의 동기화 가사를 한 번 더 찾는다. 이전 일반 가사 캐시도 온라인 사용이 허용되어 있으면 동기화 가사로 갱신을 시도한다. 반복 요청을 막기 위한 간격을 두고, 사용자가 직접 선택한 일반 가사는 명시적인 ‘실시간 가사 다시 찾기’ 동작으로 바꿀 수 있다. 다시 찾기는 기존 로컬 파일을 고치지 않으며 명시적으로 온라인 조회를 수행한다. 온라인 검색이 꺼져 있으면 곡 정보 전송 안내 후 사용자가 켜도록 한다.

실제 재생 시계에 맞춰 현재 줄을 갱신하고 일시정지·앞뒤 탐색에도 반영한다. 플레이어/전체화면 재생 중에는 100ms 간격으로 갱신하며, 향상된 LRC의 단어 강조에서 앞부분 일반 텍스트 때문에 강조 위치가 어긋나는 경우도 보완했다. 검색 후보에 실시간/일반 여부를 표시한다. 시간 정보가 없는 일반 가사에 임의의 타이밍을 만들어 붙이지 않는다.

오디오 엔진·USB 형식 협상·Google 인증 범위는 변경하지 않는다. 실제 하드웨어와 개별 파일의 가사 등록 상태는 별도 확인이 필요하다.

검증: Android 16 ARM64 전체 92개 검사 통과, Lint 오류 0개. 실제 재생·일시정지·탐색 중 가사 줄 갱신과 폴더 단계 이동, 드래그 중간 상태 유지, 기존 출력/Drive/업데이트 경로를 검사했다. APK는 기존 서명 키를 유지한다.

# 설정·EQ UI 정리 — 배포 보류

2026-10-27 사용자 요청에 따라 로컬 앱 변경과 검증까지만 완료했다. 기존 홈·라이브러리 UI 검토 변경도 유지한다. GitHub 릴리스 게시, 배포 파일 준비, 공개 update.json 변경은 하지 않았다. 로컬 버전은 0.12.0/code16이며 다음 실제 배포 전에 올려야 한다.

## 설정

- 테두리 없는 둥근 카드, 부드러운 선택 색, 동일한 벡터 아이콘과 글자·간격을 사용한다.
- 사운드 / 사용 환경 / 라이브러리와 연결 / 앱 정보로 묶고 카드 내부에 목록 행을 배치한다.
- EQ와 SoX를 메인 설정에서 바로 열 수 있다. 출력 기기, 비트퍼펙트·USB·DSD 상세 설정도 유지한다.
- 가사 검색·캐시 관리는 ‘가사 설정’, 시작 시 변경 확인·음악 폴더 관리는 ‘라이브러리 관리’에 정리했다. 기존 설정 값·권한·캐시 삭제 확인·폴더 제거 동작은 유지한다. 시스템 뒤로가기는 실제 방문 경로로 돌아가며 설정 탭 선택을 유지한다.
- 오디오 상세·SoX의 제목, 선택 항목, 슬라이더 수치와 스위치도 같은 스타일로 맞췄다.

## EQ

- 7밴드 / 파라메트릭 전환은 같은 선택 바를 사용한다. 그래프와 조절부는 한 카드에 통합한다.
- 7밴드는 네이티브 SeekBar를 회전해 일곱 개의 세로 슬라이더로 모았다. 각 밴드의 게인과 주파수를 함께 표시하고 터치·접근성 조절을 지원한다.
- 파라메트릭은 밴드·필터 선택을 나란히, 주파수와 게인·Q를 한 카드 안에 배치한다. 같은 밴드를 그래프에서 드래그할 때 기존 편집 뷰를 재사용한다.
- 전체/선택 밴드 응답, 선택 지점과 은은한 채움을 표시한다. Config와 출력 샘플레이트가 같으면 응답 계산을 캐시한다. 오디오 필터·헤드룸 계산식은 변경하지 않았다.
- 그래프의 밴드 지점 근처에서만 편집을 시작한다. 빈 영역 터치가 곧바로 EQ 변경으로 처리되지 않는다.
- 자동 프리앰프는 별도 카드에 수동·자동·실제 적용 값을 표시한다. 해당 카드와 수동 슬라이더는 아래로 스크롤해 확인할 수 있다. 기존 켜기/끄기·설정 보존·비트퍼펙트 우회를 유지한다.

## 검증

- assembleDebug / assembleDebugAndroidTest / lintDebug 성공. Lint 오류 0 / 경고 43.
- Android 16 ARM64, CPU 2코어·RAM 2GB 설정의 에뮬레이터에서 관련 16개 통과, 51.587초. 환경 검사 1개를 포함한다.
- 세로 슬라이더를 실제 손가락 이벤트로 조절해 선택 밴드 게인만 바뀌고 주파수가 고정되는지 확인했다. 네이티브 접근성 ACTION_SET_PROGRESS로도 같은 게인이 적용되는지 확인했다.
- 그래프의 응답 캐시를 실제 Biquad 응답과 대조하고 EQ를 끄면 평탄한 응답으로 갱신되는지 확인했다. 빈 영역 터치의 비편집 처리, 같은 밴드 드래그 시 기존 편집 뷰 재사용을 검사했다.
- 두 테마의 설정·두 EQ·오디오·SoX 화면 10개를 캡처했다. 새 관리 페이지 이동과 뒤로가기, 시작 시 검색 스위치의 저장, 기존 가사 검색 스위치 보존을 검사했다.
- 기존 EQ 프리앰프 보정·모드별 밴드 저장·메인 스레드 표지 읽기 방지 검사, 설정 부모로 복귀·그래프 밴드 선택 표시·앱 화면 실행·실제 필터 계수·재생 설정 스위치·시스템 바/검색 커서 검사를 통과했다.
- NW-ZX507 실기기나 실제 USB DAC 검증은 수행하지 않았다. 오디오 엔진과 네이티브 코드는 변경하지 않았다.

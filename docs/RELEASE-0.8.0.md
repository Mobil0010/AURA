# AURA 0.8.0 · 화면과 탐색 사용성 정리

홈의 이어 듣기에 표지와 곡 정보를 함께 배치하고 긴 제목·앨범·아티스트 이름의 줄 수를 제한했다. 라이브러리 탭과 저장소 선택을 전용 칩으로 바꿔 고정 높이 안에서 글자가 잘리지 않도록 간격을 통일했다. 재활용 목록에서 카드 위 여백이 사라지던 문제도 수정했다.

라이브러리에서 앨범·아티스트·폴더를 열었다가 돌아오거나 탭을 바꾸면 이전 목록 위치를 복원한다. 목록 상태는 화면 재생성용 저장 상태에도 포함한다. 검색창에 지우기 버튼을 추가하고 앞뒤 공백을 무시하며, 검색 결과 없음·기기 음원 없음·Drive 음원 없음·초기 불러오기 상태를 구분한다. 화면 갱신 중 검색 입력과 커서 위치를 유지한다. 빈 라이브러리에서 로컬 폴더와 Google Drive 연결을 직접 선택할 수 있다.

곡 오른쪽 메뉴에서 한 곡 재생, 플레이리스트 추가, 해당 앨범·아티스트 보기를 제공한다. 기존 길게 누르기도 유지한다. 재생 화면에 대기열을 추가해 현재 곡과 순서를 확인하고 원하는 곡으로 이동한다. 대기열에서 곡을 골라도 기존 대기열은 유지한다. 재생 목록 변경을 반영하고, 오래된 행을 눌렀을 때 잘못된 곡으로 이동하지 않도록 확인한다. Wi-Fi 재생 대기열은 수신 기기에서 관리하도록 안내한다.

미니 플레이어에 정사각형 표지·진행 선과 재생/일시정지/불러오는 중/완료/오류 상태를 표시한다. 설정의 ‘재생과 알림’을 별도 화면으로 묶고 스위치 모양을 오디오 설정과 통일했다. Drive·출력·업데이트 등 하위 화면에 돌아가기 경로를 추가하고 선택한 탭을 접근성 설명에 포함했다. 상태 표시줄과 키보드 여백을 창 인셋으로 처리한다.

검색 중에는 진행 표시와 취소를 유지한다. 완료 안내는 직접 닫을 수 있고 성공 안내는 8초 후 사라진다. 완료된 검색 안내에서 취소 동작을 제공하지 않는다. 재생 오류는 화면에서 짧은 복구 안내를 제공하고 자세한 원인은 오류 정보 복사로 확인할 수 있다.

오디오 엔진·USB 전송·Drive 인증 권한을 바꾸는 작업은 포함하지 않는다. 기존 Google 개인 테스트 계정과 하드웨어 호환성 제한은 유지한다.

## 라이브러리 상단바와 LRCLIB 보완

라이브러리를 아래로 탐색하면 큰 제목·탭·필터·검색창을 높이 48dp의 얇은 바로 전환한다. 얇은 바에도 현재 탭, 펼치기, 검색 동작을 남기며 반대 방향 스크롤에서는 전체 상단 영역을 다시 보여 준다. 상단바가 차지하는 공간에 맞춰 목록 높이도 다시 계산한다.

LRCLIB 자동 조회에서 재생 시간이 없다는 이유로 요청을 중단하던 조건을 제거했다. [현재 LRCLIB API 문서](https://lrclib.net/docs)에 따라 곡명·가수를 보내고 앨범과 유효한 재생 시간은 선택적으로 포함한다. 정확한 조회가 404이거나 가사가 비어 있으면 구조화된 검색으로 한 차례 보완한다. 후보의 제목·가수와, 확인 가능한 재생 시간 ±2초를 대조해 다른 곡이나 다른 길이의 버전을 조용히 선택하지 않는다. null 동기화 가사는 일반 가사로 대체하고 요청 제한·서버 오류·연결 실패를 구분한다. User-Agent는 현재 앱 버전을 사용한다.

Drive에서 태그·재생 시간을 나중에 얻어도 같은 URI라는 이유로 가사 요청을 다시 하지 않던 문제도 수정했다. 조회 키에 곡 정보와 온라인 사용 설정을 포함해 정보가 보완되면 다시 조회하며 오래된 요청 결과는 세대 번호로 무시한다. 온라인 검색 기본 꺼짐, 사용자가 켠 경우에만 전송, 로컬 LRC 우선 및 저장한 가사 이용 정책을 유지한다.

검증: Android 16 ARM64에서 전체 86개 검사 통과, Lint 오류 0개. 최종 APK는 기존 서명을 유지한다. LRCLIB 실제 HTTPS 검색과 재생 시간/앨범 없는 조회 응답도 확인했다. 개별 음원에서 가사가 등록되어 있는지와 정확한 버전 일치는 서비스 데이터에 따라 달라질 수 있다.

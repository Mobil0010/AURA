# AURA 0.13.0

- 홈·라이브러리·설정·EQ·플레이리스트를 새 플레이어와 같은 둥근 카드·벡터 아이콘·파란 강조 색으로 정리했습니다. 다크·라이트 모드를 유지합니다.
- 라이브러리의 곡·앨범·아티스트·폴더 화면과 미니 플레이어를 정리하고 목록 행·표지를 재사용합니다. 설정은 기능별 카드와 가사/라이브러리 관리 페이지로 묶었습니다.
- 7밴드 EQ의 세로 조절부, 파라메트릭 편집, 주파수 응답 그래프를 통일했습니다. 그래프와 조절부는 한 카드에 두고, 자동 프리앰프 보정 기능은 유지합니다.
- 전체화면 가사에 단어 강조 스위치를 추가했습니다. enhanced LRC의 단어 시간이 있으면 해당 시간을 사용하고, 줄 시간만 있으면 ‘줄 기준 추정 강조’로 표시합니다. 음성 인식이나 실제 발음 정렬 기능은 아닙니다.
- 가사 화면의 곡 정보와 이전/재생·일시정지/다음 컨트롤은 스크롤 후 나타나고 약 3초 뒤 부드럽게 숨습니다. 가사의 위치는 컨트롤 표시 여부에 따라 바뀌지 않습니다.
- 시작 시 음악 확인은 기존 곡의 태그·표지를 유지하고 새 음원만 분석합니다. Drive는 변경 기록과 폴더 캐시를 이용하고 로컬 저장소는 파일 목록을 비교합니다. 정상 확인된 삭제 항목 정리와 조회 실패 시 기존 목록 보호를 유지합니다.
- 작은 표지의 대체 이미지에서 앨범명이 잘리는 부분을 정리했습니다.

Android 8 이상 / 네 ABI 통합 APK입니다. 기존 설치와 같은 서명을 유지합니다. 실제 NW-ZX507·USB DAC 및 사용자의 Drive 계정 데이터로 이번 버전을 검증하지는 않았습니다. 기존 Native DSD 등 구현 범위는 이전 버전과 같습니다.

이전 WIP 문서는 각 로컬 검토 시점의 기록이며, 이 릴리스에 해당 변경을 모두 포함합니다. 세부 UI와 검증 한계는 UI-HOME-LIBRARY-WIP.md, UI-SETTINGS-EQ-WIP.md, UI-PLAYLIST-LYRICS-SCAN-WIP.md 및 VALIDATION.md를 참고해 주세요.

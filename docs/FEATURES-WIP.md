# 음악 도구·음향 효과·태블릿/폴더블 — 미배포 작업

2026-10-28. 사용자 요청에 따라 구현·검사·실제 앱 캡처까지만 진행한다. 공개 GitHub 릴리스나 업데이트 피드는 변경하지 않는다. 버전은 0.18.2/code24 그대로이며, 로컬 디버그 APK의 기능은 공개 0.18.2와 다르다. 새 키나 서명 전환 경로를 변경하지 않았다.

## 홈과 음악 관리

- 홈에는 ‘스마트 플레이리스트’라는 별도 분류 없이 최근 추가한 곡, 즐겨찾는 음악, 오랜만에 듣는 곡(30일 이상), 아직 듣지 않은 곡을 실제 기록에 따라 표시한다. 장르/즐겨찾기/미청취 조건의 사용자 모음을 만들고 제거할 수 있다.
- 곡 메뉴의 음악 도구에서 즐겨찾기와 북마크 등을 관리한다. 모음은 백그라운드에서 만들며 새로 본 곡에 대해서만 추가 날짜를 기록한다. 이미 기록한 곡을 다시 메타데이터 분석하지 않는다.
- 중복 후보는 정규화한 제목·아티스트 및 2초 이내 재생 시간을 기준으로 모은다. 사용자가 표시할 버전을 고르면 다른 후보를 라이브러리에서만 숨긴다. 원본 음원을 삭제하지 않으며 숨긴 곡은 다시 표시할 수 있다. 후보는 다른 믹스/버전일 수 있으므로 사용자가 선택한다.

## 백업과 복원

- 사용자가 고른 JSON 파일에 플레이리스트·청취 통계·EQ/음향 설정·즐겨찾기·북마크·곡별 싱크·홈 조건 모음을 저장하고 복원한다. Google 토큰/계정 인증 정보·음원 파일·다른 기기에서 유효하지 않은 읽기 권한과 출력 기기 ID는 내보내지 않는다.
- 복원은 같은 기록을 합산해 중복 집계하지 않도록 통계의 고유 방문/분 버킷을 기준으로 병합한다. 설정 타입과 통계 필드를 쓰기 전에 검사한다.
- 새 기기의 폴더를 다시 연결하면 제목·아티스트·앨범·재생 시간이 같은 유일한 곡에 플레이리스트/즐겨찾기/북마크/싱크·통계를 연결한다. 후보가 여러 개인 경우 임의 연결하지 않고 기존 참조를 보존한다. URI가 이미 같은 곡은 그대로 둔다.
- 통계 100,000행/입력 JSON 24MiB 상한이 있다. 대규모 장기 기록의 스트리밍 백업은 아직 구현하지 않았다. 직접 연결한 LRC 파일의 내용과 오프라인 음악 사본은 이 설정 백업에 포함하지 않는다.

## Google Drive 오프라인 보관

- 곡, 앨범/플레이리스트 모음, 폴더 단위로 명시적으로 보관한다. Drive 원본과 섞이지 않도록 앱의 전용 내부 저장소에 사본을 저장한다.
- 포그라운드 서비스에서 순서대로 내려받아 화면을 닫아도 작업을 계속한다. 진행 상황/취소 및 보관 목록 화면을 제공한다. 미완료 파일은 별도 partial 파일로 저장하며 완료 후에만 재생 가능한 파일로 바꾼다.
- 앱의 DsdDataSource에서 보관한 파일을 먼저 열어 네트워크/로그인 없이 해당 음원의 일반 오디오를 탐색·재생할 수 있다. 계정 연결을 해제해도 사용자가 저장한 사본은 보관 목록에서 직접 제거할 때까지 유지한다.
- 보관 한도 512MiB/1GiB/4GiB/8GiB, 오래된 사본 자동 정리는 사용자가 켤 수 있다(기본 꺼짐). 현재 기기에서 재생 중인 곡은 자동 정리 대상에서 제외한다. 원본 Drive 파일을 삭제하지 않는다.
- 앱 강제 종료/프로세스 사망 후 작업 자동 재개는 구현하지 않았다. 다시 요청하면 완료한 파일은 건너뛰고 미완료 파일을 다시 받는다. 이번 네트워크 검사는 로컬 HTTP 모의 Drive를 사용했고 실제 사용자 Drive 계정의 다운로드까지 실행하지 않았다.

## 재생 편의 기능

- 취침 타이머: 15/30/60분 및 1~720분 직접 입력, 현재 곡/앨범 끝에 정지, 취소. 마지막 5초 페이드 옵션. 비트퍼펙트에서는 음량 변경 없이 정지한다. 이 기기의 재생 서비스가 소유하며 캐스트용 타이머는 제공하지 않는다.
- 북마크: 현재 곡의 위치/이름 저장, 같은 곡 또는 다른 곡에서 해당 위치로 이동, 삭제.
- A–B 반복: 현재 재생 위치를 시작/끝 지점으로 설정하고 반복한다. 최소 간격 0.5초, 곡 전환/해제 시 정리한다.
- 가사: 곡별 ±0.1초 및 밀리초 직접 입력/초기화, 로컬 LRC 연결·해제. 연결한 LRC를 먼저 사용하고 원본 파일 대신 앱 내부 사본을 보관한다. 기존 전체 가사 보정값과 곡별 보정값을 합쳐 사용한다.
- 홈 위젯: 앨범아트·제목·아티스트·이전/재생/다음 컨트롤. 실제 RemoteViews 기반이다. 위젯 미리보기 화면과 재생 제어 연결을 제공한다.

## 음향 효과

- ReplayGain: Media3가 제공하는 ReplayGain 트랙/앨범 게인과 피크 태그를 읽는다. 앨범 태그가 없으면 곡 태그, 게인 태그가 없으면 원래 음량을 사용한다. 피크 태그가 있으면 그 피크를 넘지 않게 게인을 제한하고, 피크가 없으면 양의 게인을 적용하지 않는다. 새 음량 분석기를 라이브러리에 돌리지는 않는다. 기기 재생에 적용하며 캐스트 사전 변환에서는 다른 곡의 값을 재사용하지 않도록 제외했다.
- 다이내믹 베이스: 강도 0~100%, 중심 주파수 40~160Hz. 저역 셸프와 채널 연동 피크 제어, 파라미터 변경 시 완만한 전환. Sony Clear Bass 코드나 동일 알고리즘을 사용한 것은 아니며 실제 청감/왜곡이 같다고 주장하지 않는다.
- 기존 크로스피드와 좌우 밸런스를 음향 효과 화면에서 함께 조절한다.
- 기기별 프로필: EQ·리샘플링·ReplayGain·베이스·앱 볼륨 상한을 저장하고 연결 시 자동 적용(기본 꺼짐). 출력 엔진/비트퍼펙트 설정은 프로필이 바꾸지 않는다. 식별할 수 없는 유선 이어폰은 같은 출력 유형의 프로필을 공유한다.
- 비트퍼펙트에서는 이 음향 처리/앱 볼륨 상한을 우회한다. 새로운 효과는 기본 꺼짐이므로 기존 재생 음색을 임의로 바꾸지 않는다.

## 태블릿과 폴더블

- 너비 700dp 이상 및 높이/너비 1.6 미만인 창에서 메뉴는 하단 왼쪽 5/8, 재생 상태바는 오른쪽 3/8에 배치한다. 좁거나 세로로 긴 창에서는 기존 스마트폰 배치를 사용한다.
- 상태바를 누르면 오른쪽 3/8 너비의 플레이어가 위로 올라오고 기존 본문은 왼쪽으로 공간을 내준다. 기존 목록 뷰와 스크롤 상태를 유지한다.
- 오른쪽 위 전체화면 버튼으로 전체 플레이어를 열고, 최소화 버튼으로 패널로 돌아온다. 전체화면/패널을 내리기 버튼·앨범아트 당기기 제스처·뒤로 가기로 닫으면 상태바로 돌아간다. 마지막 전체화면/패널 선택을 저장하고 다음에 열 때 복원한다.
- 태블릿 가로 전체화면은 앨범아트 왼쪽, 곡 정보·재생 컨트롤 오른쪽이다. 가사 보기는 왼쪽 일반 플레이어와 오른쪽 가사의 두 영역을 사용한다. 패널에서 가사를 열 때에는 가사를 위한 작업 영역을 펼치고, 가사를 닫으면 패널 너비로 돌아간다. 이때 저장한 전체화면/패널 설정은 바꾸지 않는다.
- 패널 너비·등장 위치·가사 표시 전환에 애니메이션을 적용한다. 시스템 애니메이션 끄기를 따른다. 이동 중 크기 변경에 따른 플레이어 재구성을 짧게 지연해 매 프레임 뷰를 다시 만들지 않도록 한다.
- 셔플·반복·대기열·곡 메뉴·USB DAC 앱 볼륨 및 오류 확인을 제공한다. 가사는 기존 곡별 보정/직접 LRC 연결을 사용하고, 글자 부분을 누르면 해당 위치로 이동한다.
- Activity 재생성 시 열린 패널 상태도 복원한다. 실제 폴더블/태블릿 물리 기기는 별도 검증이 필요하다.

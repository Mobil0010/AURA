# AURA 0.17.0

앨범아트 화질을 개선하고 곡 정보 및 실제 앱 출력 형식을 확인하실 수 있도록 했습니다.

- 앨범아트 저장 해상도를 최대 2048px, JPEG 품질을 95로 높였습니다. 작은 원본은 확대하지 않으며, 메모리가 제한된 기기에서는 표시 해상도를 최대 1024px로 조절합니다.
- 플레이어를 열면 필요한 기존 저화질 표지만 백그라운드에서 보완합니다. 기존 표지를 먼저 표시하고, 원본을 읽지 못하면 유지합니다. 로컬 내장 표지와 Google Drive 내장/같은 폴더 사진을 지원합니다. 전체 음악을 앱 시작 시 다시 읽지는 않습니다.
- 점 세 개 메뉴를 AURA의 둥근 카드·아이콘·다크/라이트 색상으로 통일하고 ‘곡 정보’를 추가했습니다.
- 곡 정보에서 태그, 코덱, 샘플레이트, 비트 깊이, 채널, 비트레이트, 재생 시간, 파일 크기 및 위치를 확인하고 복사하실 수 있습니다. 출력 설정이 아닌 파일 기준 정보이며, 확인할 수 없는 값은 추정하지 않습니다.
- 플레이어에 입력 PCM → 앱 출력 비트 깊이/샘플레이트를 표시합니다. 실제 출력 엔진이 연 형식을 사용하며 SoX 리샘플링·호환 리샘플링·비트 형식 변환을 반영합니다. 시스템 믹서나 수신 기기의 최종 출력 형식을 측정한 값은 아닙니다.
- 마지막 라이브러리 탭과 저장소별 폴더 경로를 기억합니다. 앱을 다시 열거나 홈에서 폴더를 선택하시면 마지막 경로로 복원합니다. 삭제된 폴더는 남은 상위 경로로 이동합니다.
- USB DAC별로 적용 확인된 하드웨어 볼륨을 기억하고 재연결 시 복원합니다. 복원 실패 시 저장값은 유지하고 안내합니다. 일련번호가 없는 같은 모델 여러 대는 기억값을 공유할 수 있습니다.

Android 8 이상용 universal APK이며 기존 설치와 같은 서명을 유지합니다. 실제 NW-ZX507·USB DAC·외부 캐스트 기기에서 이번 변경을 검증하지는 않았습니다. 에뮬레이터의 실제 재생 및 모의 USB 제어 검증 결과는 [검증 기록](VALIDATION.md), 동작과 화면은 [구현 기록](UI-ARTWORK-INFO-WIP.md)에 있습니다.

APK, 업데이트 정보, SHA-256, 대응 소스·빌드 안내·네이티브 라이선스를 함께 제공합니다.

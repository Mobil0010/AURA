# AURA 0.18.0 / versionCode 22

2026-10-28. 보류했던 USB 출력 엔진, 폴더 표지, 전체화면 가사와 플레이어 표시 변경을 하나의 버전으로 배포한다.

- USB DAC 미연결 시 직접 출력 선택을 비활성화하고 연결 상태를 재확인한다. 직접 출력 진입 직전의 Android 기본/Hi-Res 엔진을 기억하고 분리 시 복귀한다. 시스템 엔진을 명시적으로 선택하면 즉시 적용한다. 기존 연결/분리 일시정지 옵션을 유지한다.
- 폴더 목록은 재생 순서의 첫 곡 표지를 표시한다. 내장 표지가 없으면 로컬/Google Drive 같은 폴더의 사진을 사용하고, 없으면 폴더 아이콘을 유지한다. 비동기 로딩·제한된 썸네일 디코딩·폴더별 후보 캐시·공유 사진 저장으로 부담을 줄였다. 캐시된 음원 메타데이터를 불필요하게 다시 읽지 않는다.
- 곡을 바꾸면 전체화면 가사 스크롤을 맨 위로 초기화한다.
- 앨범아트는 원본 비율을 유지하고 기존 최대 영역 안에 맞춘다. 플레이어의 표지 영역·제목·재생 버튼 위치는 표지 비율에 따라 바뀌지 않는다.
- 재생 형식을 작은 한 줄로 표시한다. 리샘플링이 없으면 원본 비트 깊이·kHz만 표시하고, 실제 리샘플링 시 입력 → 출력과 리샘플러를 표시한다. 누르면 상세 정보를 확인할 수 있다. 이는 압축 파일의 kbps가 아닌 앱 PCM 형식이며 시스템 믹서 이후 DAC의 최종 형식을 보장하지 않는다.
- 폴더 정렬 버튼의 아이콘 표시를 수정했다.

기존 설치와 동일한 서명, Android 8 이상 universal APK. 실제 USB DAC/NW-ZX507/개인 Google Drive 계정에서의 물리적 동작은 이번 환경에서 검증하지 못했다. 검증 상세는 VALIDATION.md를 참고한다.

# AURA 0.14.0

- 저사양 기기의 라이브러리 목록에서 폴더/곡 행을 각 유형별로 재사용하고 화면 크기가 정해진 목록의 불필요한 재배치를 줄였습니다. 작은 표지는 메모리를 덜 쓰는 디코딩 설정을 사용하고, 없는 표지는 제한된 캐시에 기록해 같은 파일을 반복 조회하지 않습니다.
- 가사 줄이 바뀔 때 전체 줄에 애니메이션을 걸던 작업을 이전 줄과 현재 줄만 갱신하도록 줄였습니다. 글자 강조는 재생 상태 갱신과 분리해 화면 프레임에 맞춰 갱신합니다(저사양 모드 약 30fps 목표). 강조 영역 계산도 재사용합니다. 실제 기기 프레임률을 보장하는 수치는 아닙니다.
- 전체화면 가사의 글자 영역을 눌렀을 때만 해당 줄로 이동합니다. 위아래 여백, 줄 오른쪽 빈 공간, 단어 사이 공백은 탐색을 실행하지 않습니다. 스크롤 조작은 유지합니다.
- 전체화면 가사의 하단 컨트롤에 재생 위치 바, 현재 시간과 전체 시간을 추가했습니다. 바를 잡고 있는 동안 컨트롤을 숨기지 않으며 손을 놓으면 약 3초 뒤 부드럽게 숨습니다.
- 재생·라이브러리 검색 알림에 투명 배경의 AURA 전용 상태 아이콘을 사용합니다.
- 출력 목록에서 통화용 수화부·보호용 스피커·내부 경로를 제외해 같은 휴대폰이 여러 번 표시되는 문제를 줄였습니다. 주소가 같은 외부 출력은 묶고, 이름만 같은 서로 다른 DAC·블루투스 기기는 합치지 않습니다.
- 기본 곡 정렬을 디스크 번호→트랙 번호순으로 변경했습니다. 라이브러리/폴더와 앨범/플레이리스트 상세 화면의 정렬 버튼, 설정의 라이브러리 관리에서 제목·아티스트·앨범·재생 시간·저장 순서와 오름차순/내림차순을 선택할 수 있습니다. 선택은 공통으로 저장됩니다. 정렬 계산은 백그라운드에서 실행합니다.
- 로컬/Drive 메타데이터에 트랙·디스크 번호를 저장합니다. 번호가 없는 기존 목록은 제목순으로 표시되며 ‘모든 폴더 다시 검색’을 한 번 실행하면 기존 음원에서 번호를 읽습니다. 시작 시 변경 확인은 기존 음원을 재분석하지 않고 새 곡만 읽는 정책을 유지합니다.

Android 8 이상 / 네 ABI 통합 APK, 기존 설치와 동일한 서명입니다. 실제 NW-ZX507·Samsung S25·USB DAC를 연결해 프레임률이나 출력 경로를 측정하지는 않았습니다. 가사의 단어 시간이 없으면 줄 기준 추정 강조를 사용하며, 오디오 엔진과 기존 Native DSD 구현 범위는 이전 버전과 같습니다.

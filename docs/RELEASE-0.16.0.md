# AURA 0.16.0

하단에 **통계** 탭을 추가했습니다. 음악을 얼마나, 무엇을 많이 들었는지 기간과 분류별로 확인하실 수 있습니다.

- 일·주·월·전체 기간의 청취 시간, 재생 횟수, 감상한 곡 수를 확인하실 수 있습니다. 이전 기간으로 이동하거나 날짜를 선택하실 수 있습니다.
- 곡·아티스트·앨범·장르별 순위와 장르 필터를 제공합니다. 청취 시간 또는 재생 횟수 순서로 정렬하실 수 있습니다.
- 총 청취 시간을 시간·분·초 단위로 표시합니다. 순위 항목을 누르면 정확한 청취 시간, 감상한 날짜 수, 처음·마지막 청취 시각 및 기기 저장소/Google Drive 청취 시간을 확인하실 수 있습니다.
- 시간대별·날짜별·최근 12개월 그래프를 제공합니다. 막대를 누르면 해당 구간의 상세 시간이 표시됩니다.
- 기록은 이 기기에만 저장합니다. 기록 저장을 끄거나 확인 후 전체 기록을 삭제하실 수 있습니다.
- 백그라운드에서도 재생 서비스가 기록하며, 일시정지·버퍼 정지·탐색으로 건너뛴 구간은 집계하지 않습니다. 30초 이상 감상하거나 1분보다 짧은 곡의 절반에 해당하는 시간을 감상하면 1회로 집계합니다.
- 화면 밖에서 기록을 집계하고 순위는 한 페이지에 20개씩 표시해 화면의 부담을 줄였습니다. AURA의 다크·라이트 테마를 모두 지원합니다.
- 로컬/Google Drive 메타데이터의 장르 태그를 보존합니다. 이전에 추가하신 곡의 장르가 비어 있으면 해당 폴더를 다시 검색해 주세요. 앱 시작 시 이미 있는 곡을 강제로 다시 읽지는 않습니다.

통계는 이 기능을 추가한 이후의 감상부터 기록하며 과거 기록을 생성하지 않습니다. 캐스트 청취 시간은 수신 기기가 보고하는 재생 위치로 추정합니다. 온라인 앨범아트 검색 기능은 추가하지 않았습니다.

Android 8 이상용 universal APK이며 기존 설치와 동일한 서명을 사용합니다. 사용자의 실제 NW-ZX507 또는 외부 Cast/DLNA 수신 기기에서 이번 통계 기능을 검증하지는 않았습니다. 에뮬레이터의 실제 WAV 재생과 자동 검증 결과는 [검증 기록](VALIDATION.md) 및 [구현 기록](UI-STATISTICS-WIP.md)에 있습니다.

APK와 함께 업데이트 정보, SHA-256, 대응 소스·빌드 안내·네이티브 라이선스 ZIP을 제공합니다.

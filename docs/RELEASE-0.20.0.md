# AURA 0.20.0 · USB DAC 볼륨 팝업

- USB 직접 출력에서 볼륨을 조절하면 플레이어 화면 밖에서 하단 재생바 위에 볼륨 팝업이 나타납니다.
- 180ms 등장/220ms 퇴장 애니메이션을 사용하며 마지막 조작 후 3초에 닫힙니다. 다시 조절하면 표시 시간이 연장됩니다.
- 오디오 설정에서 앱 내부 표시와 백그라운드 표시를 따로 선택합니다. 앱 내부는 기본 켜짐, 백그라운드는 기본 꺼짐입니다.
- 다른 앱 위에 표시하려면 권한이 필요하며, 먼저 용도를 안내합니다. 권한 설정에서 허용한 뒤 오디오 설정에서 다시 켜 주세요.
- 실제 플레이어/가사/오른쪽 플레이어 패널에서는 팝업을 숨깁니다.
- 기존 기기별 하드웨어 볼륨 기억과 미지원 DAC의 소프트웨어 볼륨 경로를 유지합니다.

Android 9 및 API36 에뮬레이터에서 UI와 USB 모의 장치를 사용해 검사했습니다. 실제 DAC/제조사별 백그라운드 제한은 별도 검증이 필요합니다. 전체 검사 기록은 VALIDATION.md를 참고하세요.

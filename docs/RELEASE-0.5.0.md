# AURA 0.5.0

## USB DAC 연결과 전환

SIMGOT DEW4X에서 보고된 `USB format configuration: LIBUSB_ERROR_IO`에 대응해 UAC2 설정 순서를 수정했다. 스트리밍 인터페이스를 유휴 alternate setting으로 바꾸고 AudioControl 인터페이스를 확보한 뒤 현재 클록 주파수를 확인한다. 이미 일치하면 SET_CUR를 생략한다. 읽기 전용 클록에 쓰지 않으며, 변경이 필요한 쓰기 가능 클록은 제한된 대기/재확인으로 **실제 읽힌 주파수가 요청과 일치하는 경우에만** 사용한다. 활성 clock selector의 연결을 따라가며, 알 수 없는 clock topology는 거부한다. 오류에는 실패 단계·AS/AC 인터페이스·alternate setting·클록 ID·요청 형식을 포함한다. 피드백 값의 스레드 간 접근도 원자적으로 바꿨다.

- 재생 서비스가 USB 장치/오디오 출력 연결 변화를 감시한다. Activity를 닫아도 재생 중인 서비스에서 동작한다.
- 일반 Android USB 출력도 연결 시 자동 선택한다. 직접 출력을 이전에 사용했고 새 연결의 USB 권한도 있으면 직접 연결을 복원한다. 권한이 없으면 Android USB 출력으로 전환하며 비트퍼펙트를 끈다. USB 권한을 자동 승인하지 않는다.
- 분리 시 휴대전화 스피커를 선택하고 직접 출력·비트퍼펙트·DoP를 해제한다. 분리 시 일시정지는 설정에서 선택하며 기본값은 켜짐이다.
- 수동 Bluetooth/스피커 선택을 추적해서 사용하지 않는 USB 기기를 뽑았을 때 그 출력을 덮어쓰지 않는다.
- 자동 선택은 설정에서 끌 수 있다. 기존 공식 비트퍼펙트는 다시 연결한 기기의 공식 지원 정보가 있는 경우에 복원하며, 실제 형식은 기존 출력 초기화 검사도 통과해야 한다.

클록 제어 동작을 확인할 때 [Linux USB 오디오 클록 처리](https://github.com/torvalds/linux/blob/master/sound/usb/clock.c)를 참고했다. 소스 코드를 복사하지 않고 독립적인 협상 함수와 가짜 전송을 이용한 검사를 작성했다. DEW4X 실물 연결/전송 및 비트 동일성은 이 환경에서 검증하지 못했다. 모든 DAC가 지원된다는 의미는 아니다.

## 라이브러리

- 설정에서 폴더를 여러 개 등록/제거한다. 안드로이드 폴더 선택기는 한 번에 한 폴더씩 추가한다. 이전 단일 폴더 설정을 자동으로 읽는다.
- 등록한 폴더를 함께 검색하며 같은 제공자/문서 ID는 중복으로 등록하지 않는다. 겹치는 하위 폴더도 중복 탐색하지 않는다.
- 크기·수정 시각을 확인해 변경되지 않은 음악 메타데이터를 재사용한다. 변경 시각을 제공하지 않는 파일은 다시 읽는다. 앨범아트 캐시가 지워졌으면 복구를 위해 다시 읽는다.
- 메타데이터는 두 작업 스레드에서 읽고 대기 작업 수도 제한한다. 검색용 텍스트도 곡 로드 때 만들어 입력마다 대량 문자열을 다시 만들지 않는다.
- dataSync 포그라운드 서비스가 검색을 소유한다. Activity 종료/화면 이동 후에도 계속하며 앱 상단과 저소음 진행 알림에 상태를 표시한다. 폴더 탐색 단계는 미확정 진행률, 이후는 완료 곡/전체 곡과 진행 막대를 사용한다.
- 알림이나 앱 상단에서 취소할 수 있다. 폴더 읽기 실패나 취소 시 기존 곡 목록을 유지한다. OS의 강제 종료·사용자의 앱 강제 중지 뒤에 자동 재시작하는 작업은 아니다.
- Android 13 이상은 알림 권한을 요청한다. 사용자가 거부한 알림을 강제로 표시할 수는 없다.

## 알림과 플레이어

- 알림의 일시적인 오디오 포커스 요청에 음악 볼륨을 20%로 낮출지, 일시정지할지 설정한다. 통화/다른 앱의 일시 독점은 일시정지하며 종료 후 자동 재생 여부도 선택한다. 영구 포커스 손실은 자동으로 재개하지 않는다.
- 비트퍼펙트 및 USB 직접 출력에서는 샘플 보존을 위해 볼륨 감소 대신 일시정지한다. Android의 포커스 정책은 우회하지 않는다. [Android 오디오 포커스 문서](https://developer.android.com/media/optimize/audio-focus)
- 재생 화면은 별도 전체 화면으로 표시하고 앨범아트 크기를 가용 화면에 맞춰 키웠다. 1:1과 CENTER_CROP을 유지한다.
- 재생 버튼 아래에 현재/다음 동기화 가사를 표시한다. 로컬 LRC 및 설정에서 허용한 LRCLIB를 공유해서 사용한다. 누르면 기존 전체화면 가사로 이동한다.
- 긴 출력 오류 안내를 주요 재생 버튼 아래로 옮겨 조작 영역을 밀어내지 않도록 했다.

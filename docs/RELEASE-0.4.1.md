# AURA 0.4.1

## 출력 연결

- Android 공식 비트퍼펙트와 앱의 USB 직접 출력 경로를 구분한다. USB 직접 출력에 Android 14 조건을 적용하지 않는다.
- 비트퍼펙트 활성화·출력 엔진 변경·설정 적용 전에 USB 연결/권한과 공식 지원 정보를 검사한다. 미지원이면 기존 재생 설정을 유지하고 연결 안내를 제공한다.
- 공식 비트퍼펙트 지원 USB 출력이 하나이면 자동으로 선택하며 여러 개이면 명시적인 선택을 요구한다. 다른 출력으로 조용히 바꾸거나 지원하지 않는 형식을 비트퍼펙트라고 표시하지 않는다.
- USB 직접 출력을 선택하면 기기 선택과 권한 허용부터 진행한다. 연결 뒤 기존 재생 위치·재생 의도를 유지해 재준비한다.
- 일반 스피커 등으로 전환할 때는 비트퍼펙트 해제를 확인한다. 준비되지 않은 설정으로 이전 큐를 자동 준비해 즉시 오류를 내지 않는다.
- 재생 화면에 긴 MediaCodec 내부 오류를 반복 출력하는 대신 연결 실패 상태와 원인을 분리한다. 실제 USB 전송과 개별 DAC 호환성 검증은 여전히 필요하다.

## 플레이어와 모션

- 표지·헤더를 아래로 쓸어내리면 이전 화면으로 닫힌다. 짧게 끌면 원위치로 복귀한다. 스크롤 중이거나 재생 위치 슬라이더 영역에서 시작한 제스처는 닫기로 처리하지 않는다.
- 하단 탭은 짧은 페이드, 플레이어는 아래에서 진입, 가사는 페이드/확대, 상세 설정은 좌우 전환을 사용한다. 시스템 애니메이션 끄기 설정을 따른다.
- 이전/다음 버튼과 가운데 재생 버튼 사이를 24 dp씩 띄웠다. 이전/다음은 평평한 버튼, 재생은 큰 민트 버튼으로 구분한다.
- 아이콘을 상단 compound drawable 대신 버튼의 실제 중앙에 그린다. 재생/일시정지는 내용만 짧게 교차 전환한다.

## 앨범아트

홈·앨범 그리드·곡 목록·그룹·재생 화면에 공통 정사각형 표시기를 사용한다. 원본을 강제로 늘리지 않고 CENTER_CROP으로 비율을 유지한다. 가로/세로 원본은 중앙을 기준으로 일부 잘릴 수 있으며 표시 영역은 1:1이다.

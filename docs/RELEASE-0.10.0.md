# AURA 0.10.0 · 라이브러리 최적화와 Drive 정보 사전 읽기

라이브러리의 펼친 상단바를 제목·곡 수·저장소 선택·검색 버튼과 네 개 탭으로 줄였다. 검색 입력은 필요할 때 연다. 접힌 상태에서는 48dp의 현재 탭·검색·펼치기 바를 유지한다. 손가락을 따라 접히는 동안 목록 높이를 매번 바꾸지 않고 위치와 표시 범위를 갱신한다. 스크롤의 인위적인 속도 감소와 큰 터치 임계값은 제거해 Android 기본 동작을 사용한다. 상단바에는 별도의 작은 움직임 여유를 유지한다.

곡 검색과 앨범·아티스트·폴더 분류는 전용 작업 스레드에서 처리한다. 오래된 검색 결과가 최신 검색어의 결과를 덮어쓰지 않으며, 화면을 벗어난 결과를 적용하지 않는다. 변경되지 않은 로컬 파일의 정보를 재사용할 때 파일마다 별도의 작업을 만들지 않는다. 정렬 키를 미리 계산하고 JSON 복원 때 중복 Track 생성을 제거한다. 홈에는 표시할 여덟 앨범의 그룹만 만든다.

Drive 폴더 검색 단계에서 아직 읽지 않았거나 변경된 파일의 태그·길이·앨범아트를 순차적으로 미리 읽는다. 검색 중 진행 상황을 앱과 알림에 표시하며, 전체 인덱스를 곡마다 다시 읽고 저장하지 않고 한 번에 반영한다. 취소·계정 변경 시 미완료 목록을 반영하지 않는다. 태그가 없거나 형식을 읽지 못하면 파일명을 유지하며 다음 검색에서 다시 시도한다. 기존 Drive 곡은 업데이트 후 폴더를 다시 검색한다. 음원 전체를 저장하지 않으며 정보 읽기도 곡당 최대 4 MiB 전송 예산/1 MiB 블록 캐시를 사용한다. 읽을 수 있는 모든 파일에 태그나 표지가 존재함을 보장하지 않는다.

플레이어에 새로 진입하거나 곡이 바뀌면 화면 맨 위에서 시작한다. 가사 화면에서 플레이어로 돌아올 때 가사 화면을 뒤로 가기 기록에 다시 넣지 않는다. 아래로 내려 플레이어를 닫으면 가사가 다시 열리지 않으며, 이전 화면에 돌아간다. 이전 화면의 지연된 스크롤 복원과 가사 자동 스크롤이 새 화면에 영향을 주는 경로도 차단한다.

구형 Android에서 고비트 출력 형식을 구성하는 단계가 실패하면 자동 형식의 16비트 호환 출력 후보를 시도하도록 예외 처리 범위를 수정했다. 명시적으로 지정한 형식과 비트퍼펙트는 자동 변경하지 않는다.

오디오 블록의 직접 버퍼와 샘플 배열을 재사용하고 EQ 계수를 설정이 바뀔 때만 다시 계산한다. 중복 DSP 초기화를 제거하고 Media3 음원 버퍼의 목표를 8 MiB, 시간 범위를 5~15초로 설정한다. 앨범아트 캐시는 4 MiB로 제한하고 메모리 경고 시 비운다. 큰 이미지 디코딩이 메모리 부족을 일으키면 기본 표지를 표시한다. 설정의 ‘앱 종료 기록 복사’는 Java 종료의 예외 종류·코드 위치·마지막 오디오 단계를 복사한다. 계정·파일 주소·예외 메시지는 기록하지 않으며 시스템 강제 종료나 네이티브 오류까지 포착하지는 못한다.

NW-ZX507 실기기와 Android 9에서의 재생 검증은 수행하지 않았다. 이 릴리스는 메모리·할당 부담과 확인된 화면 오류를 개선하며, 해당 기기의 종료 원인을 특정하거나 완전히 해결했다고 단정하지 않는다. 재발하면 설정의 종료 기록으로 추가 원인을 확인해야 한다. 비트퍼펙트와 USB 직접 출력은 자동으로 다른 출력으로 낮추지 않는다.

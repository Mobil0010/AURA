# AURA 0.18.2 / versionCode 24

2026-10-28. 전용 배포 키로 서명을 전환하면서 기존 설치의 설정과 데이터를 유지하는 업데이트 경로를 제공한다.

## 기존 앱에서 업데이트

1. 기존 AURA에서 업데이트를 확인하고 0.18.1 호환 업데이트를 설치한다.
2. 앱을 다시 열어 업데이트를 한 번 더 확인하고 0.18.2를 설치한다.

앱을 삭제하거나 데이터를 초기화할 필요가 없다. 두 설치 모두 Android의 마지막 설치 확인은 사용자가 진행한다. 0.18.1은 서명 교체를 이해하는 검사기로 전환하는 단계이며, 0.18.2가 최신 본 버전이다.

Android 13 이상은 새 전용 키 및 v3.1 서명 교체 증명을 적용하고, Android 8–12는 동일 APK의 기존 서명을 유지해 구형 기기에서 계속 업데이트할 수 있도록 했다. NW-ZX507의 Android 9도 이 호환 경로를 사용한다.

이전 버전은 `update.json`에서 고정 전환용 0.18.1을 안내받는다. 전환 이후 버전은 `update-v2.json`에서 최신 버전을 확인한다. 향후 릴리스에도 동결한 전환 APK와 두 피드를 함께 제공한다. 서명 검사에서 기존 현재 서명으로부터 증명된 정방향 교체만 허용하고, 무관한 서명과 역방향 교체는 거절한다.

## 검증과 범위

공개 0.18.0 APK를 출발점으로 API28(Android9)/API36(Android16) ARM64 에뮬레이터에서 앱 삭제 없이 다음 버전까지 설치했다. UID·설정·폴더 경로·앱 내부 데이터가 유지됐다. 전환 검사 13개, 초기 데이터 준비 2개, 실제 재생/탐색/백그라운드/메모리 부하 검사 각 환경 1개씩 통과했다. release APK는 debuggable이 아니며 API28 및 API33–36 서명 검증을 통과했다. 신규 Google 로그인 인증서도 기존 항목을 유지한 채 등록했다.

실제 S25/NW-ZX507 하드웨어와 실제 Google 계정 로그인/Drive 스트리밍은 이번 검사에서 검증하지 않았다. 정식 서명은 Play 프로텍트나 삼성의 외부 설치 안내를 제거하는 인증이 아니다. 자세한 기록은 SIGNING-MIGRATION.md 및 VALIDATION.md에 있다.

## 배포 파일

- AURA-0.18.2.apk: 최신 본 버전
- AURA-0.18.1-bridge.apk: 기존 앱의 무삭제 전환용
- update.json / update-v2.json: 기존 및 전환 이후 업데이트 정보
- SHA256SUMS.txt: 두 APK의 체크섬
- AURA-0.18.2-source.zip: 대응 소스·빌드 안내·네이티브 라이선스. 전환용 APK는 동일 코드에서 `-PauraVersionCode=23 -PauraVersionName=0.18.1`로 빌드해 기존 키로 서명한 고정 파일이다. 검증용 code25 APK와 개인 키·암호·로컬 SDK·개인 설정은 포함하지 않는다.

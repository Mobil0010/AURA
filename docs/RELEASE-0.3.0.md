# AURA 0.3.0 · 화면과 재생 안정성 개선

## 화면

- 공통 색상·글자·카드·버튼·설정 선택창을 통일했다. 설정창에서 버전은 실제 빌드 번호를 표시한다.
- 이모지 대신 크기에 맞춰 그리는 단색 아이콘을 사용한다. 설정은 톱니바퀴 모양이다.
- 화면 진입 페이드/이동, 버튼 누름, 탭 전환, 가사 강조 애니메이션을 추가했다. 시스템 애니메이션 배율이 0이면 생략한다.
- 재생 화면에서는 미니 플레이어를 숨기고 표지와 재생 버튼을 중심으로 배치한다. 음악을 선택하기 전에도 미니 플레이어를 숨긴다.
- 라이브러리 목록 높이를 실제 화면에 맞추고 검색을 짧게 지연해 불필요한 전체 목록 재생성을 줄였다. 폴더명도 검색한다.

## 수정한 동작

- 하위 화면의 뒤로 가기가 이전 화면으로 돌아간다. 그룹·검색·탐색 기록은 화면 재생성 시 복원한다.
- 캐스트 중 진행 시간/탐색 막대와 가사를 갱신하며, 가사 줄을 누르면 해당 재생 기기에 탐색 명령을 보낸다.
- 가사를 직접 스크롤하면 5초 동안 자동 따라가기를 멈춘다. 이전 줄의 단어 강조가 남지 않게 한다.
- EQ 그래프에서 고른 밴드를 선택창에도 반영하고 수치를 갱신한다. 제스처 취소 시 스크롤 잠금을 해제한다.
- 오래된 Native DSD 설정으로 선택창 인덱스가 범위를 벗어나지 않게 한다.
- 재생 화면의 오래된 컨트롤 참조를 초기화한다. 종료된 화면에는 비동기 UI 작업을 적용하지 않고, 백그라운드에서는 화면 갱신 타이머를 중지한다.

## 오디오 오류 처리

`ERROR_CODE_AUDIO_TRACK_INIT_FAILED`와 `MediaCodecAudioRenderer error`는 기기·선택 형식·하위 원인에 따라 나타날 수 있다. 사용자가 보고한 실제 기기의 전체 오류 로그는 아직 확보하지 않았다.

- `getMinBufferSize` 확인뿐 아니라 실제 AudioTrack 생성 실패까지 처리한다. 자동 비트 깊이는 원본 형식 → 같은 샘플레이트의 16 bit → 원본 레이트 자동 모드일 때 48 kHz/16 bit 순서로 가능한 형식을 시도하고, 실제 적용 형식을 표시한다.
- 비트퍼펙트·USB 직접 출력·명시한 비트 깊이·명시한 SoX 샘플레이트는 해당 조건을 벗어나 임의로 대체하지 않는다.
- flush 중에는 출력을 즉시 다시 열지 않는다. 다음 데이터 도착 때 열고, 실패를 AudioSink 초기화 예외로 전달한다.
- 잘못된 채널 마스크와 초기 볼륨 누락을 보완했다.
- 재생 실패 시 하위 원인을 표시하고, 기본 출력 복구 및 오류 정보 복사 버튼을 제공한다. 복사 정보에는 앱/OS/기기, 출력 상태, 예외 연결이 포함된다.

에뮬레이터에서 오류를 주입한 형식 재시도 검사와 실제 AudioTrack 탐색 후 재개 검사를 수행했다. 이는 사용자가 쓰는 실제 폰에서 같은 오류가 해결됐다는 확인과는 구분한다.

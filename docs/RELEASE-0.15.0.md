# AURA 0.15.0

## Google Drive 캐스트

- Drive 음원을 Google Cast 및 UPnP/DLNA 수신 기기로 보낼 수 있도록 기존 차단을 제거했습니다. 로컬/Drive가 섞인 현재 재생 대기열을 사용합니다.
- 폰이 인증된 Drive 구간 요청을 수행하고, 임의의 세션 링크로 필요한 데이터만 수신 기기에 중계합니다. 음원을 통째로 다운로드해 저장하지 않으며 Google 로그인 토큰·Drive API 주소를 수신 기기에 전달하지 않습니다.
- GET/HEAD/OPTIONS 및 일반/끝부분 byte range, 길이·MIME·CORS 응답을 제공합니다. 메모리와 동시 요청 수를 제한하며 계정이 변경되거나 연결을 종료하면 이전 중계 요청을 차단합니다.
- 중계용 알림과 백그라운드 서비스를 추가했습니다. 폰 화면을 닫아도 중계를 유지하고 알림에서 재생/일시정지·이전 곡·종료를 조작할 수 있습니다. 종료 시 수신 기기 정지를 요청하고 중계·Wi-Fi/CPU 잠금을 해제합니다.
- Cast 대기열은 전체 목록을 유지하며 수신 기기에 일부 항목씩 나누어 전달합니다. 같은 제목의 서로 다른 곡도 중계 URL로 구분합니다.
- 폰과 수신 기기는 같은 Wi-Fi에 있어야 합니다. Drive 캐스트는 원본 중계이며 EQ·SoX를 적용하지 않습니다. 로컬 음원의 기존 WAV 변환 경로는 유지합니다. 수신 기기에 따라 코덱/샘플레이트 지원이 다릅니다. 실제 Cast 스피커·Chromecast 실물 연결 검증은 수행하지 않았습니다.

## 폴더 표지와 부분 검색

- 시작 시 기존 곡을 건너뛰면서 빠졌던 Drive 폴더 표지를 음원 재분석 없이 보완합니다. 이전 인덱스는 저장한 폴더 목록으로 한 번 보완한 뒤 변경 확인 경로를 사용합니다.
- 같은 폴더의 cover/folder/front/album/albumart/artwork 및 다른 JPG/JPEG/PNG/WebP 후보를 찾습니다. 먼저 고른 사진이 손상되면 다음 후보를 시도합니다. 유효한 내장 표지는 우선 유지합니다.
- 폴더 사진은 16MiB까지 임시 파일로 제한해 받아 512px 이하 JPEG로 저장합니다. 압축 이미지 전체를 메모리에 올리지 않습니다. 폴더 사진 한 장을 곡마다 다시 다운로드하지 않습니다.
- 폴더 화면의 ‘이 폴더만 다시 검색’, 또는 폴더 목록을 길게 누르는 메뉴에서 선택한 폴더와 하위 폴더만 다시 읽을 수 있습니다. 로컬과 Drive 모두 지원합니다. 다른 폴더의 기존 곡은 유지하며 선택 범위의 추가/삭제/정보 변경만 반영합니다. 목록 조회가 실패하거나 취소되면 해당 작업의 라이브러리 인덱스를 교체하지 않습니다.
- 부분 검색도 백그라운드 서비스와 앱/알림 진행 상황을 사용합니다. Drive의 전체 변경 커서는 부분 검색으로 건너뛰지 않습니다.

## 폴더 재생·정렬·선택창

- 폴더 목록 오른쪽에 재생 버튼을 추가했습니다. 이름을 누르면 폴더를 열고, 재생 버튼을 누르면 하위 폴더를 포함한 곡 전체를 선택한 정렬순으로 재생합니다.
- 트랙 번호가 없는 기존 곡은 파일명의 `02`, `1-02` 같은 번호를 보조 기준으로 사용합니다. 제목·아티스트·앨범의 숫자도 2→10의 자연스러운 순서로 비교합니다. 태그의 디스크/트랙 번호가 우선이며 정렬 설정과 오름/내림차순을 유지합니다.
- 출력 엔진·정렬·재생 기기·확인/입력 등 앱이 만드는 선택창에 둥근 배경, 앱 색상, 글자·버튼 간격을 공통 적용했습니다. 다크·라이트를 지원하며 안드로이드 권한 창은 시스템 화면으로 유지합니다.

검증 내역은 VALIDATION.md를 참고해 주세요. Android 8 이상 / 네 ABI 통합 APK이며 기존 설치와 동일한 서명을 유지합니다. USB 네이티브 엔진과 기존 Native DSD 구현 범위는 변경하지 않았습니다.

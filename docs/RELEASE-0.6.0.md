# AURA 0.6.0 · Google Drive 스트리밍

설정 → Google Drive에서 계정을 연결하고 음악 폴더를 여러 개 추가할 수 있다. 검색한 곡은 로컬 음원과 같은 곡·앨범·아티스트·플레이리스트에서 재생하며, 폴더 탭에서는 기기 저장소와 Google Drive를 구분한다. 전체/기기 저장소/Google Drive 필터도 제공한다.

음원 전체를 내려받아 저장하는 방식 대신 최대 1 MiB 범위 요청을 이어서 재생한다. 탐색 시 해당 위치부터 요청하며, 토큰 만료는 한 차례 갱신한다. 폴더 검색 중 음원을 내려받지 않고 파일명과 폴더명으로 먼저 표시한 뒤 재생한 곡의 태그와 표지를 제한된 메모리 범위에서 읽는다. 백그라운드 검색, 진행 알림, 취소, 실패 시 기존 목록 유지가 적용된다.

같은 이름의 LRC가 폴더에 있으면 동기화 가사로 사용한다. 계정 연결을 해제하면 Drive 목록·표지·가사 캐시와 대기열의 Drive 항목을 제거하며 로컬 음원은 유지한다. 원본 Drive 파일은 수정하거나 삭제하지 않는다.

Google Play 서비스와 인터넷이 필요하다. 개인 테스트 등록 계정만 Google 로그인을 사용할 수 있으며 공개 OAuth 검증은 완료되지 않았다. Drive의 DSD·바로가기·Cast/DLNA는 지원하지 않는다. 실제 Google 계정의 승인 및 실기기 재생은 모의 서버 검사와 별도로 확인해야 한다. 자세한 등록/데이터 처리는 [Google Drive 문서](GOOGLE_DRIVE.md)를 참고한다.

검증: Android 16 ARM64에서 전체 66개 검사 통과. 새 Drive 검사는 HTTP 범위/탐색, 만료 토큰, 비정상 응답 차단, 폴더 중복 제거, 실패 시 목록 유지, 메타데이터 읽기 제한, 저장소별 화면, 64 MiB WAV의 실제 Media3 스트리밍을 포함한다. 기존 USB DAC 실물 호환성 검증 범위는 확대하지 않았다.

# AURA 0.20.5

새 블루투스 기기의 코덱 조회가 CDM 등록 부족으로 거부되면 앱이 앞에 있을 때 Android 등록 승인창을 자동 요청합니다. 설정에서 등록 버튼을 직접 찾는 단계를 줄였습니다. 같은 기기로 자동 요청을 반복하지 않으며 취소한 경우에는 설정에서 수동으로 다시 등록할 수 있습니다. 기기별 최초 시스템 승인은 여전히 사용자가 직접 해야 합니다.

Release 빌드와 lintDebug/lintVitalRelease, 서명 및 16KB ZIP 정렬 검사를 완료했고 SM-S931N에 업데이트 설치했습니다. 이번 자동 요청 변경의 신규 미등록 기기 승인·취소 흐름은 실기기에서 아직 재현 검증하지 않았습니다. 기존 CDM 승인과 LDAC/SSC 조회는 0.20.4에서 실기기로 확인했습니다.

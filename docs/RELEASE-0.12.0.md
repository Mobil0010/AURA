# AURA 0.12.0 · EQ 자동 보정·7밴드·화면 테마·목록 개선

## EQ

EQ 자동 프리앰프 보정을 기본으로 켠다. 각 필터의 실제 계수를 사용해 전체 직렬 응답의 최대 증폭을 계산하며, 선형·로그 주파수 표본과 국소 피크 탐색을 함께 사용한다. 자동 적용 값은 수동 값과 ‘최대 증폭의 음수 − 1dB’ 중 더 작은 값이다. 평탄한 응답에는 추가 1dB를 적용하지 않는다. 더 낮게 설정한 수동 프리앰프는 보존한다. EQ를 끄거나 자동 보정을 끄면 수동 값을 사용한다. 비트퍼펙트 경로에서는 기존처럼 DSP를 우회한다.

자동 감쇠는 증폭을 올릴 때 즉시 반영하고, 보정을 풀 때는 완만하게 복귀한다. 필터 계수·출력 샘플레이트별 결과를 캐시해 같은 오디오 블록마다 응답을 재계산하지 않는다. 화면에 수동·자동·실제 적용 값을 표시하며 전체 응답 그래프에도 적용한다. 이는 필터의 정상 상태 주파수 피크에 대한 여유로, 모든 과도 신호·후단 DAC·헤드폰의 왜곡 방지를 보장하는 리미터는 아니다.

7밴드 그래픽 EQ(60·150·400·1k·2.5k·6k·12kHz, ±12dB, Q=1 피킹)와 파라메트릭 EQ 중 선택할 수 있다. 그래픽 EQ는 주파수·Q·종류를 고정하며 게인만 변경한다. 두 방식의 밴드는 각각 저장하고 프리앰프·자동 보정·EQ 활성 상태는 공유한다. 기존 사용자는 파라메트릭 설정을 유지한다. 기존 프리셋을 읽을 때 새 필드를 기본값으로 이관한다.

## 화면

[Music Player App — Nabil mahmud / UI Deft](https://dribbble.com/shots/15301542-Music-Player-App)의 밝은 바탕, 앨범 카드와 원형 파란 재생 버튼을 참고했다. 디자이너의 이미지·음원·화면 자료는 앱에 포함하지 않는다. 홈의 이어 듣기 표지를 키우고 앨범을 가로 카드로 배치한다. 재생 화면은 닫기·곡 메뉴를 갖춘 상단, 큰 정사각형 표지, 가운데 곡명·아티스트, 양끝 시간 표시로 재구성한다. 링이 있는 원형 재생 버튼과 중립색 이전/다음 버튼에 충분한 간격을 두고 무작위·전체/한 곡 반복을 제공한다. 가사·대기열 바로가기는 작은 아이콘과 글자로 표시하며 하단 가사는 현재 한 줄만 보여 준다. 출력 연결은 얇은 링크로 표시하고 상세 샘플레이트·버퍼 상태는 출력 기기 화면에서 확인한다. 기존 표지 드래그 닫기와 USB 전용 볼륨을 유지한다. 장식용 가짜 파형은 추가하지 않는다.

설정 > 화면 > 화면 테마에서 다크·라이트·기기 설정을 선택한다. 기본은 다크이며 선택은 저장한다. 본문·대화상자·EQ·Drive·업데이트·상태 표시줄에 같은 색 체계를 적용한다. 무거운 실시간 블러나 그림자 처리를 추가하지 않는다.

## 라이브러리

표지 파일 확인·이미지 크기 읽기·디코딩을 단일 백그라운드 작업자로 옮긴다. 메인 스레드는 메모리 캐시만 조회하고 대기 이미지를 표시한다. 기존 저사양 1MiB/일반 4MiB 캐시를 유지하며 작업 대기열을 제한한다. 재사용한 행에 이전 곡 표지가 늦게 도착하지 않도록 바인딩 토큰으로 검사한다. 검색·Drive 정보 갱신 세대로 캐시를 구분한다.

곡 목록과 그룹의 곡 목록에서 행·텍스트·표지 뷰·리스너를 재사용한다. 폴더의 하위 곡 수는 트리를 만들 때 계산해 표시할 때마다 하위 폴더를 다시 순회하지 않는다. NW-ZX507 실기기에서의 프레임 속도나 충돌 해결을 측정한 결과는 아니다.

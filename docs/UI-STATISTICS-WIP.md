# 청취 통계 구현 — 배포 보류

2026-10-27. 사용자의 최신 요청에 따라 구현·로컬 검증·실제 앱 캡처까지만 수행했다. 앱 버전은 0.15.0/code19로 유지했다. 공개 릴리스, 업데이트 피드, dist 파일은 변경하지 않았다. 이 작업의 로컬 APK는 기존 공개 0.15.0 APK와 다른 미배포 빌드이다.

## 화면

[stats.fm 공식 화면](https://stats.fm/)과 공식 지원 문서의 [차트](https://support-new.stats.fm/hc/en-us/articles/59061730156441-Charts-and-the-stats-screen), [순위](https://support-new.stats.fm/hc/en-us/articles/59061649002265-Top-tracks-artists-and-albums)를 참고했다. 기간 선택, 큰 청취 시간 요약, 재생 횟수/감상한 곡 수, 막대 그래프, 분류별 순위를 AURA의 색상·카드·공통 선택창·다크/라이트 테마로 구현했다. 다른 서비스의 이미지·브랜드 자산은 사용하지 않았다. 취소된 온라인 앨범아트 검색 기능은 추가하지 않았다.

- 하단에 통계 탭을 추가했다. 일·주·월·전체 기간과 이전/다음 기간, 날짜 선택을 지원한다. 주는 월요일부터, 월은 달력 기준이며 휴대폰 시간대를 사용한다.
- 곡·아티스트·앨범·장르 순위를 청취 시간 또는 재생 횟수로 볼 수 있다. 장르 필터와 20개 단위 페이지를 사용한다.
- 합계는 시간·분·초까지 표시한다. 순위 항목을 누르면 정확한 시간, 재생 횟수, 감상한 날짜 수, 처음/마지막 청취 시각, 기기 저장소/Drive 청취 시간을 표시한다. 이 상세 정보는 선택한 기간과 장르 안의 기록이다.
- 그래프는 일 화면의 시간대별, 주/월 화면의 날짜별, 전체 화면의 최근 12개월 청취 시간을 보여준다. 막대를 누르면 해당 구간의 초 단위 시간이 표시된다.
- 기록 저장 켜기/끄기 및 확인 후 전체 삭제를 지원한다. 과거 청취 기록은 추정하거나 생성하지 않는다.

## 기록과 성능

PlaybackService와 CastRelayService에 기록기를 연결했다. 화면이 꺼지거나 앱이 백그라운드로 이동해도 서비스가 기록한다. 로컬 재생과 캐스트가 중복 집계되지 않도록 로컬 기록은 캐스트 활성 상태에서 중단한다. 캐스트는 추가 네트워크 요청 없이 기존 수신 기기 상태와 위치를 사용하므로 추정값이다. 실제 Cast/DLNA 기기에서 이 기록 기능을 검증하지는 않았다.

단조 증가 시계와 실제 재생 위치의 변화를 비교한다. 일시정지·버퍼 정지·탐색 점프·비정상적으로 지연된 샘플은 제외한다. 자연스러운 곡 반복/곡 전환은 새 감상으로 구분한다. 30초 또는 짧은 곡의 절반에 해당하는 시간에 도달하면 1회로 센다. 짧게 들은 구간의 시간은 남지만 재생 횟수는 0회일 수 있다. 5초 주기 및 재생 상태/위치 변경 시에 기록하므로 강제 종료 시 마지막 주기 일부는 유실될 수 있다.

SQLite WAL과 시간 인덱스, 감상 세션·분 단위 집계를 사용한다. 쓰기와 순위/상세 조회는 한 백그라운드 작업 큐에서 수행한다. 오디오 스레드와 화면 스레드에서 DB를 열거나 집계하지 않는다. 통계 화면 자동 갱신은 30초 간격이고, 백그라운드 화면의 갱신과 오래된 요청을 중단한다. 목록은 한 페이지 20개로 제한하며 그래프 그리기 중 문자열/날짜 객체를 만들지 않는다.

음원의 장르 태그를 로컬/Drive 메타데이터, Track JSON 및 재생 대기열에 보존한다. 기존 태그가 없는 인덱스를 앱 시작 시 강제로 다시 읽지 않는다. 이전 곡은 사용자가 폴더를 재검색하거나 전체 메타데이터 검색할 때 장르가 채워진다. 누락 장르는 ‘장르 없음’으로 표시한다.

## 검증

- assembleDebug, assembleDebugAndroidTest, lintDebug 성공. lint 오류 0개 / 경고 47개. 새 그래프의 draw allocation 경고를 제거했다. 남은 신규 경고는 한국어 동적 상세 문구의 SetTextI18n이다.
- API36 ARM64, CPU2, RAM2GB 에뮬레이터에서 통계·실제 재생/볼륨·증분 검색·Drive 태그/표지·저사양 UI·폴더/공통 선택창 관련 48개 통과, 131.652초.
- 이후 상세 시간/최초·최근 시각 DB 열과 UI를 추가한 빌드에서 통계·실제 재생·증분 검색 17개 통과, 66.918초.
- 마지막 그래프 터치/선택창·정렬 안정화 수정 후 최종 APK에서 통계 7개 재검사 통과, 23.575초. 이전 48개 전체를 마지막 수정 후 다시 실행했다고 주장하지 않는다.
- 통계 검사: 일시정지/버퍼 정지/탐색/샘플 지연, 2배속 시계, 자정 분리, 일광절약시간 23/25시간 일자, 월요일 주 경계, 월 경계, 장르 필터/정렬/페이지, JSON/대기열 장르 보존, 초 단위 상세 시간/최초·최근 시각, 빈 기록, 다크/라이트 및 5개 하단 탭 접근을 검증했다.
- 실제 3초 WAV를 ExoPlayer로 반복 재생한 서비스형 기록기가 청취 시간과 별도 반복 횟수를 남기는지 확인했다. Activity 없이 실행하며 일시정지·탐색·기록 끄기 후 합계가 증가하지 않는지 검사했다.
- 기존 서명 인증서 SHA-256 `d41fcccff7efb833e448e27aaac0b176454ee70772c358b678edb9a7ea5db89a`의 APK 서명 검증 성공. 개인 키는 공개하지 않았다.
- NW-ZX507 실기기와 실제 외부 캐스트 기기에서의 성능/기록 정확도는 미검증이다.

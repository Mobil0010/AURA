# 목록 포맷 배지·Hi-Res·Drive 표지 보관 — 미배포

2026-10-29. 사용자 요청으로 개발·검사·실제 화면 캡처까지만 진행했다. 공개 릴리스·업데이트 피드·배포 서명은 변경하지 않았다. 로컬 개발 버전은 기존 0.20.1/code27 후보를 유지한다.

## 음악 목록

- 전체 곡, 폴더 내부, 앨범·아티스트·플레이리스트 상세, 대기열의 공통 곡 행에 재생 시간 바로 왼쪽 포맷 배지를 추가했다.
- 파일명/저장한 형식/MIME에서 FLAC·MP3·M4A·WAV·AAC·OPUS·AIFF 등을 표시한다. 근거 없는 형식은 추정하지 않고 배지를 숨긴다. Drive 파일명은 인덱스 URI의 name 정보를 사용한다.
- FLAC 헤더 STREAMINFO의 원본 샘플레이트가 44.1kHz 초과이면서 비트 깊이가 16bit 초과일 때 녹색 Hi-Res를 표시한다. 예: 24bit/48kHz·24bit/96kHz. 나머지 또는 미확인 FLAC은 파란 FLAC이다. 출력 리샘플링 설정은 판정에 쓰지 않는다. 인증·실제 녹음 품질을 보증하는 표시는 아니다.
- 샘플레이트·비트 깊이를 인덱스에 저장하고 복제·JSON 왕복에서도 유지한다. 목록 바인딩에는 파일/네트워크 읽기가 없다. 새 검색의 FLAC은 헤더를 읽고, 기존 정보가 없는 FLAC은 해당 폴더/전체 다시 검색으로 보완한다. 앱 시작 증분 확인은 기존 Drive 음원을 일괄 재분석하지 않는다.
- 재활용 시 포맷 문구·색상·표시 여부를 갱신하며 다크/라이트를 지원한다.

## Drive 앨범아트

- 기존 Drive 표지는 정리 가능한 cache/art에 있었으며, 캐시 소실 시 원본의 태그·표지를 다시 읽게 되는 구조였다. 사용자 실제 기기의 캐시 소실 여부나 지연 시간은 직접 측정하지 않았다.
- Drive 곡별 표지를 files/drive-art로 옮겨 앱 재실행·메모리 캐시 초기화·일반 캐시 정리 후에도 디스크 사본을 사용한다. 로컬 음원의 저장 위치는 유지한다. 폴더 공용 표지는 기존 files/drive-folder-art를 사용한다.
- 남아 있는 이전 JPEG는 백그라운드 라이브러리/표지 작업에서 이동하고, 유효한 고화질 표식도 보존한다. 구형 저해상도 표지를 고화질로 오인하지 않는다. 이미 OS가 삭제한 표지는 최초 한 번 다시 받아야 한다.
- 계정 연결 해제 시 현재 계정 목록의 영구 표지·이전 캐시·표식을 함께 정리한다. 앱 삭제/데이터 삭제 시 영구 표지도 삭제된다. 오프라인 음원 사본 정책은 변경하지 않는다.

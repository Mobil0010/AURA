# AURA 0.20.1 / versionCode 27 — 미배포 후보

- 이미 구현된 USB 직접 출력·SoX·파라메트릭 EQ·Cast 등을 미구현으로 표시하던 이전 로드맵 화면과 분기를 제거했습니다. 현재 오디오·출력·캐스트 설정은 유지합니다.
- 개발 현황, Drive 오프라인 보관·캐스트, ReplayGain, 업데이트 피드와 서명 전환 안내를 현재 구현에 맞췄습니다.
- 과거 WIP·검증 문서에 후속 배포 상태와 기록 시점을 표시했습니다. 기존 검사 결과와 실제 기기 미검증 범위는 유지했습니다.
- Windows 한글 작업 경로에서 CMake가 종료되는 문제를 피하도록, 영문 임시 폴더에서 빌드하고 APK·lint 보고서를 돌려주는 `tools/build-windows.ps1`을 추가했습니다. 네이티브 의존성 버전과 오디오 코드는 유지합니다.
- 곡 목록의 재생 시간 왼쪽에 파일 포맷을 표시합니다. 원본이 16bit 초과·44.1kHz 초과로 확인된 FLAC은 녹색 Hi-Res로 표시합니다. 폴더·앨범·플레이리스트·대기열에 공통 적용합니다.
- Drive 앨범아트를 앱 내부 영구 저장소로 보관하고 이전 캐시를 재사용해, 일반 캐시 정리 후 원본에서 표지를 다시 읽는 상황을 줄였습니다.
- Drive FLAC 메타데이터 직접 읽기와 16KiB 앞부분 요청을 추가했습니다. 일반 기기는 최대 4곡을 동시에 분석하고 자원 절약 기기는 1곡을 유지하며, 변경 없는 정보는 재사용합니다. 공개 배포는 계속 보류합니다.
- 직접 관리하는 앱·테스트·빌드 코드 171개를 언어별 포매터로 정리하고 코드 스타일 설정을 추가했습니다. 정리 전후 Java 바이트코드와 네이티브 실행 코드는 동일합니다. 회귀 검사 실패 항목을 포함한 상세 결과는 VALIDATION.md를 참고해 주세요.

목록·Drive 표지 변경은 사용자 요청으로 미배포이며 새 debug/test APK와 21개 회귀 검사 및 실제 화면 캡처까지만 완료했습니다. 아래 release 빌드 기록은 그보다 앞선 문서/안내 정리·Windows 빌드 수정 시점입니다.

디버그 및 미서명 release APK 빌드와 lintDebug를 완료했습니다. 두 APK 모두 0.20.1/code27, 네 ABI 라이브러리와 16KB ZIP 정렬을 확인했습니다. 디버그 APK는 테스트용이며 공개 앱 업데이트용 서명이 아닙니다.

공개 최신 버전은 0.20.0/code26입니다. 이 체크아웃에는 `.local/signing/`과 동결 전환 APK가 없어 배포를 진행하지 않았습니다. 기존 키·암호·lineage와 전환 APK를 안전한 백업에서 복원한 후 공식 서명·검증·패키징·게시가 필요합니다. 새 배포 키를 만들지 않습니다. 수행한 검사는 [VALIDATION.md](VALIDATION.md)를 참고해 주세요.

# AURA 0.20.2

- 폰 스피커 선택 기록 때문에 새 블루투스 출력으로 전환되지 않는 문제를 수정했습니다.
- 새 유선·USB 연결, 외부 출력 사용 중 블루투스 재연결, 연결 해제 시 일시정지와 마지막 출력 복원 정책을 정리했습니다.
- 출력 기기 화면에 시스템이 제공하는 블루투스 코덱 정보를 표시합니다. 정보가 제한된 기기에서는 확인 불가로 표시합니다.
- Android의 기기 추가 알림만으로 블루투스 수동 연결과 자동 재연결을 구분할 수 없어 외부 출력 사용 중에는 해당 출력을 유지합니다.

디버그 빌드·lint 및 Android 15 에뮬레이터 회귀 검사 15개가 통과했습니다. 실제 WAV 재생·24회 탐색 및 곡 전환·일시정지와 재개·백그라운드 재생을 포함합니다. 실제 블루투스·USB 하드웨어 전환과 코덱 수신은 미검증입니다.

# AURA

Android 8 이상용 개인 음악 플레이어 개발 버전입니다.

## 다운로드와 업데이트

[최신 릴리스](https://github.com/Mobil0010/AURA/releases/latest)에서 APK를 설치할 수 있습니다. 앱 0.4.0부터 설정 → 앱 업데이트에서 새 버전 확인, APK 다운로드 및 안드로이드 설치 화면 연결을 제공합니다. 설치 확인은 사용자가 직접 진행해야 합니다.

릴리스의 `update.json`은 버전, APK 주소, 파일 크기 및 SHA-256을 제공합니다. 앱은 현재 설치된 AURA와 동일한 서명의 APK만 업데이트로 허용합니다.

## 개발 상태

SoX 리샘플링, EQ 응답 그래프, 음악 라이브러리, LRCLIB 가사, USB 직접 PCM, Cast/DLNA 및 같은 Wi-Fi 원격 제어를 개발하고 있습니다. Native DSD는 미지원이며 실제 USB DAC와 스피커의 기기별 검증은 남아 있습니다. 모든 기기의 모든 출력 모드를 보장하지 않습니다.

릴리스에 첨부된 소스 묶음에는 빌드 안내와 libsoxr/libusb 등 네이티브 구성 요소의 대응 소스 및 라이선스가 포함됩니다. 서명 개인 키는 공개하지 않습니다.
